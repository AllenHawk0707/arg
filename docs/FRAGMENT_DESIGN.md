# FRAGMENT_DESIGN — 片段式剧情 · 实时链路（RELAY）

> ⚠️ 剧透文档。玩家禁读。
> 对应实现：`contact.html`（自包含，无后端）。

---

## 这是什么

EDENFALL 的剧情不通过章节页面整段讲述，而是由一个**未知发信人**通过第二条终端通道——`contact.html`——**一片一片地推给玩家**。

主终端（`start.html`）是"冷档案"：信号、坐标、日志，都是过去时的死物。
实时链路（`contact.html`）是"活的"：有人正在向你说话，用打字机一样的节奏，一句一句地来。

---

## 发信人设定：RELAY

- 自称 **RELAY**（中继）。签名偶尔退化为 **R.**。
- 拒绝回答身份（"a relay passes a signal. it doesn't originate one."）。
- 玩家在现实中可考证的锚点：README 里那条匿名信息（2025 年 4 月，"你正在看的东西，已经被某人刻意放在这里让你看见"）——就是同一个人。
- 关键暗示（F-015）：2023.06.16 当天在 Landeyjahöfn 渡轮上，亲眼看着救援人员从岛上搬下**七个箱子**，而海岸警卫队报告写的是"一无所获"。RELAY 是目击者，不是研究员。身份保留到章节 99 才揭示。
- 语气规则：全小写英文、短句、不用感叹号、偶尔出现冰岛语地名。**永远比玩家多知道一点，永远不肯多说那一点。**

## 呈现原则（片段式叙事的五条铁律）

1. **它先开口**。玩家打开 `contact.html`，是 RELAY 主动接入，而不是玩家呼叫。
2. **片段永远不完整**。每段只给一个事实 + 一个钩子。完整图景只存在于玩家的 `journal.md` 里。
3. **时间戳会漂移**。大部分片段标 2025.04（实时），少数片段是 RELAY "从载波噪声里挖出来"的 **2023.06 原始通讯**（F-014）——两个时间层的混入是刻意的不安感。
4. **有损传输**。个别片段（F-003）到达时被 `█` 遮挡，玩家必须 `reread` 重新同步——把"信道不可靠"变成一个玩家亲手完成的动作。
5. **应答但不回答**。玩家的 `reply` 会被回应，但回应永远 deflect。玩家不是在对话，是在**从一块石头里敲出回声**。

## 机制

| 命令 | 行为 |
|---|---|
| `inbox` | 列出已收到的片段（编号/时间戳/首句） |
| `reread <n>` | 重读片段；被 `█` 损坏的片段第一次 reread 时**重新同步为明文** |
| `reply <text>` | 向 RELAY 发话，按关键词触发应答 |
| `wait` | 监听载波，检查是否有新解锁的片段抵达 |
| `help / clear / about / exit` | 常规 |

- **打字机推送**：每个片段逐字符打出（每 tick 2 字符），头部显示 `┌─ INCOMING ─` / `│ F-00x · 时间戳` / `└────`。
- **进度门（gate）**：片段读取 `localStorage` 中主终端写入的旗标，未达标时不投递：
  - `ef7.p002`（主终端 `coords 63.442,-20.273` 确认）→ F-007 … F-013
  - `ef7.anchor1`（主终端 `anchor eastfjord`）→ F-014 … F-016
- **已读持久化**：`ef7.contact`（JSON：已收片段、已修复损坏、应答次数），刷新页面不重播。
