# EF — EDENFALL

> 一个庞大的、关联现实的解密叙事 ARG。

---

## 你将面对什么

- **不是一款游戏**。这是一段持续运行的"调查"——你扮演 2025 年新加入调查组的协议分析师，手里握着七年前失联的研究站留下的加密求救信号。你需要一层层剥开它，直到看见真相。
- **没有存档密码提示**。没有 BOSS 难度滑块。需要你自己做研究：在线搜索、阅读论文、计算、推理、记笔记。
- **会指向现实**。某些谜题要求你打开浏览器、访问真实网站、查阅真实 PDF、查地图、听广播频率、看星空。**这并非装饰**——它们是解谜链条上的真实环节。
- **是协作的**。强烈建议与他人一起解。ARG 自 1994 年以来从未被打穿过独行者纪录。遇到瓶颈请与同好讨论。

## 难度等级

| 等级 | 表现 |
|---|---|
| 入门 | 你需要 base64 / 凯撒密码的基础知识 |
| 中级 | 你需要 Vigenère、AES、隐写术、读代码、画棋盘 |
| 高级 | 需要研究论文、查地图/街景、听频谱、写脚本 |
| 终局 | 需要跨学科整合 + 心理学 + 数学直觉 |

**目标群体**：硬核 ARG 玩家（Cloudmakers / Cicada 3301 难度档）。
**预计通关时间**：20–60 小时（单人）/ 8–20 小时（协作）。
